## 📑 Hasil Milestone 1

Dokumentasi lengkap perencanaan sistem dapat diakses pada berkas:  
👉 [**`docs/perancangan.md`**](./docs/perancangan.md)

Dokumentasi tersebut mencakup:
1. **Hirarki Struktur Menu Navigasi:** Perencanaan layout Sidebar dan Topbar admin panel.
2. **Konsep ER-D Sederhana (Mermaid.js):** Relasi entitas data (Pengguna, Guru, Kelas, Siswa, Mata Pelajaran, Nilai, dan Presensi).
3. **Design System Awal di Figma:** Color palette (*Dark Slate Indigo & Cyan Accents*), tipografi (*Plus Jakarta Sans*), dan spesifikasi komponen reusable (*Glass Cards, Form Inputs, Buttons, Badges*).
4. **Wireframe & Skema Komponen:**
   - Rancangan wireframe cepat menggunakan **Stitch by Google** (tersedia di folder `assets/img/`).
   - Tautan High-Fidelity UI Design di **Figma**.
